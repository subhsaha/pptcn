Install the package—or own the source.

Use npm for the compact API. Use the shadcn registry when you want every layout decision copied into your project.

Package

Start in one line.

npm install pptcn

Then import components from pptcn and write an ordinary .pptx file.

Source-owned

Add only what you need.

npx shadcn@latest add https://subhsaha.github.io/pptcn/r/chart-slide.json

Replace chart-slide with data-table-slide, metric-grid, or another component.
